API docs

GitHub Pages cannot run a server. This site uses a free Supabase project as the backend. HexXstrap can call the same REST API later with the user’s JWT.

Not configured yet. Put your Supabase URL and anon key in js/config.js, then follow the README in the website folder.

Config shape

{
  "settings": {},
  "fastFlags": {},
  "robloxGlobal": {},
  "nvidiaFlags": {},
  "extra": {},
  "updatedAt": "2026-08-27T00:00:00.000Z"
}

PUT/upsert replaces the whole blob. Unknown keys go into extra. These settings keys are stripped: ApplyLaunchAccount, LaunchAccountFileName, LaunchLoggedOut, MAC fields, and anything whose name looks like cookie/password/token/secret.

Auth

Supabase Auth, email + password. After login you get a Bearer JWT.

POST {SUPABASE_URL}/auth/v1/signup
POST {SUPABASE_URL}/auth/v1/token?grant_type=password
POST {SUPABASE_URL}/auth/v1/recover
PUT  {SUPABASE_URL}/auth/v1/user   (new password, Authorization: Bearer)

Headers: apikey: ANON_KEY and Authorization: Bearer ANON_KEY (or user JWT after login).

Data (PostgREST)

GET  {SUPABASE_URL}/rest/v1/profiles?username=eq.{name}&select=*
GET  {SUPABASE_URL}/rest/v1/profiles?is_public=eq.true&username=ilike.*q*&select=username,updated_at
GET  {SUPABASE_URL}/rest/v1/configs?user_id=eq.{uuid}&select=*
POST {SUPABASE_URL}/rest/v1/configs   (upsert own row, Prefer: resolution=merge-duplicates)
PATCH {SUPABASE_URL}/rest/v1/profiles?id=eq.{uuid}

Header Content-Type: application/json. Database columns: settings, fast_flags, roblox_global, nvidia_flags, extra, updated_at.

Example save body

{
  "user_id": "<your-user-uuid>",
  "settings": { "DarkTextures": true, "DarkTextureShade": 110 },
  "fast_flags": { "FFlagSomething": "True" },
  "roblox_global": {},
  "nvidia_flags": {},
  "extra": {}
}

Setup

  1. Create a free project at supabase.com
  2. SQL Editor → paste and run supabase/schema.sql
  3. Authentication → Providers → Email on. For testing, turn off “Confirm email”.
  4. Authentication → URL Configuration: Site URL = this GitHub Pages URL; Redirect URLs include /reset.html
  5. Project Settings → API → copy URL + anon key into js/config.js
  6. Push this website folder to a GitHub repo and enable Pages (root of that repo).
