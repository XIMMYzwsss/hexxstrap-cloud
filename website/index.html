What gets saved

App settings, FastFlags, Roblox global/GBS options, and NVIDIA flags. The API keeps unknown fields so future HexXstrap versions still sync.

What stays local

The Accounts tab, Roblox cookies, login files, passwords, tokens, and MAC addresses are never stored here.
